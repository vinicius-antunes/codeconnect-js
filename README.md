# 💻 CodeConnect

Interface web para publicação de projetos de programação, permitindo selecionar uma imagem, preencher informações e organizar tecnologias por tags.

O projeto foi desenvolvido durante os estudos de JavaScript para praticar manipulação do DOM, eventos, leitura de arquivos, promises e operações assíncronas.

## ✨ Funcionalidades

- Seleção e pré-visualização de uma imagem local;
- Exibição do nome do arquivo selecionado;
- Adição de tags previamente disponíveis;
- Remoção individual de tags;
- Preenchimento do nome e da descrição do projeto;
- Simulação assíncrona da publicação;
- Limpeza completa do formulário pelo botão **Descartar**.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e formulário da aplicação;
- **CSS3:** layout, cores e identidade visual;
- **JavaScript:** interações e regras da interface;
- **FileReader API:** leitura da imagem selecionada;
- **Git e GitHub:** versionamento e armazenamento do projeto.

## 🧠 Conceitos praticados

- Manipulação do DOM;
- Eventos de clique, alteração e teclado;
- Delegação de eventos;
- `async` e `await`;
- Promises;
- `FileReader` e `readAsDataURL()`;
- `Array.from()`, `map()` e `includes()`;
- Template strings;
- Tratamento de erros com `try...catch`.

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/vinicius-antunes/codeconnect-js.git
```

2. Abra a pasta no Visual Studio Code.
3. Execute o `index.html` utilizando a extensão **Live Server**.

## ℹ️ Observação

A publicação é apenas uma simulação de estudo. O projeto ainda não envia os dados para um servidor ou banco de dados e utiliza um resultado aleatório para representar sucesso ou erro.
